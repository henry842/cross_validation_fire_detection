# 🔥 Fire Detection — Cross Validation

Modelo de **Regressão Logística** para previsão de incêndios florestais a partir de dados ambientais, com validação cruzada (Cross-Validation) para garantir robustez estatística dos resultados.

## 🎯 Objetivo

Prever a ocorrência de incêndios com base em variáveis ambientais como temperatura, umidade, VOCs (compostos orgânicos voláteis) e material particulado, avaliando a estabilidade do modelo através de K-Fold Cross-Validation.

## 🛠️ Tecnologias

`Python` `Scikit-Learn` `Pandas` `Regressão Logística` `Cross-Validation`

## 📊 Metodologia

- Análise exploratória dos dados ambientais
- Pré-processamento e padronização das variáveis
- Treinamento de modelo de Regressão Logística
- Validação cruzada (K-Fold) para avaliação robusta de performance
- Métricas de avaliação: acurácia, precisão, recall e F1-score
